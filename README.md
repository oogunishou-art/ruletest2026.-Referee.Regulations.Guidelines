# JBAルールテスト 2026

バスケットボール競技規則（JBA 2026年度版）の学習・審判技術向上のためのPWAアプリです。

## 主な機能

- 175問の◯×問題（競技規則・インプリメンテーション）
- 複数の学習モード：番号順・シャッフル・クイズ・弱点復習・SRS（間隔反復法）・デイリー
- 審判活動記録・学習履歴・目標設定・試合登録
- ダッシュボード表示
- ダークモード / フォントサイズ調整 / 音声読み上げ
- localStorage による学習データ保存
